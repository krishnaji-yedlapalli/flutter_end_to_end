# Product Overview

Flutter End to End (`sample_latest`) is a multi-platform Flutter reference application that demonstrates best practices for building production-grade apps across Android, iOS, macOS, Linux, Windows, and Web from a single codebase.

It serves as a learning resource and showcase for:
- Clean Architecture with BLoC pattern
- Material 3 theming (light/dark)
- Localization with bidirectional (LTR/RTL) support (en, es, hi, he)
- Responsive/adaptive UI across screen sizes
- Offline-first data with SQLite + Firebase sync
- Push notifications (remote via FCM, local via flutter_local_notifications)
- Deep linking
- Product flavors (flutter, dart)
- IoT/smart home control (Raspberry Pi, MQTT)
- Embedded device support (Raspberry Pi with Flutter Linux embedding, touch display UI)
- Generative AI integration

The "Schools" feature is the canonical example of the full architecture stack (BLoC + Clean Architecture + CRUD + offline support).

A private submodule `daily_tracker` exists but is access-restricted.
